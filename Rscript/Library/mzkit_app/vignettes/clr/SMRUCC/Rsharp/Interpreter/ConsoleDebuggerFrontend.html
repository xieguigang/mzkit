ConsoleDebuggerFrontend

Description

调试器的控制台交互前端

这个类型是 DebuggerContext 之上的一个默认的交互实现, 其通过订阅 @E:SMRUCC.Rsharp.Interpreter.DebuggerContext.OnBreakpointHit 事件的方式 来与调试器的内核进行交互. 因为调试器的内核之中并不包含任何的 控制台相关的代码, 所以GUI的宿主程序也可以采用完全相同的方式来 实现自己的调试界面

# namespace SMRUCC.Rsharp.Interpreter

}
